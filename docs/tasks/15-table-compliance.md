## Current state

The renderer uses Word's `Table Grid` style (all four borders, single line),
emits a single `Таблица N — Name` caption, and repeats the header row on
continuation pages via `tblHeader`. Everything else from §7.7 is missing.

## Implementation

1. Extend `TableNode` with optional fields:
   - `number: str | None` (generated by Task 09 numbering context),
   - `unit_label: str | None`,
   - `continuation: ContinuationLabel | None`
     (`Продолжение | Окончание`, used when the table spans multiple pages),
   - `notes: tuple[TableNote, ...]` (each `TableNote(marker, text)`),
   - `column_units: tuple[str | None, ...]` (per column, `, Гц` style),
   - `header_levels: int` (allow more than one header row).
2. V2 parser accepts:

   ```
   [TABLE id=t1 caption="Параметры" unit="МПа" continuation=continuation
          column_units="-,Гц,°С" header_rows=2]
   | Колонка 1 | Колонка 2 | Колонка 3 |
   |-----------|-----------|-----------|
   | …         | …         | …         |
   [/TABLE]
   ```

3. Render order:
   - Above the table: optional unit label, right-aligned, 12 pt
     (`SFUTableUnit` style).
   - Caption paragraph (`Таблица N — Name`), left-aligned, 14 pt, no period.
   - Table itself with a custom `SFUTable` style:
     - left, right, bottom borders only;
     - a double line separates the last header row from the body;
     - 12 pt body, 12 pt bold centred header;
     - `tblHeader` element on the header rows so they repeat on
       continuation pages;
     - replace the header on continuation pages with a numbering row
       (column numbers `1, 2, 3, …`) when `continuation != None`;
     - `Продолжение таблицы N` / `Окончание таблицы N` paragraph
       above each continuation block.
   - Notes inside the table: appended as a final row spanning all columns,
     marker (`*` or `1)`) in superscript, text in 12 pt.
4. Validator checks:
   - reject `Номер по порядку` / `№ п/п` columns (case-insensitive);
   - reject diagonal-split cells (look for `<m:d>` or `<a:graphic>` with
     diagonal lines);
   - header text must not end with a period;
   - body font 10–12 pt;
   - cell padding 6 pt vertical;
   - italic letter designations (regex `^[a-zA-Zα-ωΑ-Ω]$` cells default to
     italic) — Task 04's `common.table.italic_letters` rule.
5. Flip these registry rules to `IMPLEMENTED`:
   - `common.table.borders`,
   - `common.table.subheader`,
   - `common.table.no_period_in_header`,
   - `common.table.unit_label`,
   - `common.table.column_unit_suffix`,
   - `common.table.continuation_label`,
   - `common.table.numbering_row_replacement`,
   - `common.table.forbid_serial_column`,
   - `common.table.no_diagonal_split`,
   - `common.table.footnote`,
   - `common.table.italic_letters`,
   - `common.table.cell_padding`,
   - `common.table.body`,
   - `common.table.spacing_before/after`.

## Tests

- A `Номер по порядку` column produces
  `common.table.forbid_serial_column` diagnostic.
- A header cell with text `Параметр.` produces
  `common.table.no_period_in_header`.
- A multi-page table renders `Продолжение таблицы 3` above the second page
  and `Окончание таблицы 3` above the third.
- Unit label `, МПа` placed above the table; validator confirms 12 pt.
- A table with two header rows repeats both on the next page.
- Diagonal-split header cell triggers
  `common.table.no_diagonal_split`.
- Notes row renders below the body but above the closing border, with
  marker `*` rendered in superscript.
