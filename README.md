# Конвертер TXT в DOCX (Стандарт СФУ)

Инструмент для конвертации текстовых файлов в формат DOCX с автоматическим применением стилей согласно стандарту Сибирского Федерального Университета.

## Установка

```bash
git clone https://github.com/Nikita2005qwe/sfu_converter.git
cd sfu_converter
```

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
# или
source .venv/bin/activate  # macOS/Linux

pip install -r requirements.txt
```

## Использование

### Запуск консольного приложения

```bash
cd src
python main.py 
```

## Формат входного файла

### Заголовки

```
[H1] Заголовок первого уровня (по центру, жирный)
[H2] Заголовок второго уровня (слева, жирный)
[H3] Заголовок третьего уровня (слева, обычный)
```

### Вставка изображений

```
[IMAGE=../images/filename.png]
Рисунок 1 - Описание рисунка
```

Путь к изображению указывается относительно директории `images/`.
Путь к изображению опционален.

### Подписи таблиц

```
[TABLE_CAPTION] Таблица 1 - Описание таблицы
```

Название для таблицы является опциональным

### Шаблон заполнения таблицы

```
[TABLE_START]
[TABLE_CAPTION] Таблица 1 - Данные
| Заголовок 1 | Заголовок 2 | Заголовок 3 |
| Ячейка 1.1 | Ячейка 1.2 | Ячейка 1.3 |
| Ячейка 2.1 | Ячейка 2.2 | Ячейка 2.3 |
[TABLE_END]
```


### Обычный текст

Просто пишите текст без маркеров. Будет применен стиль:
- Шрифт: Times New Roman, 14pt
- Выравнивание: по ширине
- Отступ первой строки: 1.25 см
- Межстрочный интервал: 1.5

## Стандарты оформления

### Основной текст
- Шрифт: Times New Roman, 14pt
- Цвет: черный
- Выравнивание: по ширине
- Отступ первой строки: 1.25 см
- Межстрочный интервал: 1.5
- Интервалы перед/после абзаца: 0

### Заголовок 1
- Выравнивание: по центру
- Жирный шрифт
- Межстрочный интервал: 1.0
- Отступ первой строки: 0

### Заголовок 2
- Выравнивание: слева
- Жирный шрифт
- Межстрочный интервал: 1.0
- Отступ первой строки: 0

### Заголовок 3
- Выравнивание: слева
- Обычный шрифт
- Межстрочный интервал: 1.0
- Отступ первой строки: 0

### Подпись к рисунку
- Выравнивание: по центру
- Отступ первой строки: 0
- Межстрочный интервал: 1.5

### Подпись к таблице
- Выравнивание: слева
- Отступ первой строки: 0
- Межстрочный интервал: 1.5

## ⚠️ Важное предупреждение: Кириллические символы в маркерах

### Проблема

Маркеры форматирования должны использовать **латинские символы**. При копировании из Word или наборе в русской раскладке визуально идентичные кириллические буквы ломают парсинг:

| ❌ Неправильно | ✅ Правильно | Причина |
|----------------|--------------|---------|
| `[Н1]` | `[H1]` | Кириллическая **Н** (U+041D) вместо латинской **H** (U+0048) |
| `[Н2]` | `[H2]` | Кириллическая **Н** вместо латинской **H** |
| `[ТABLE_START]` | `[TABLE_START]` | Кириллическая **Т** (U+0422) вместо латинской **T** (U+0054) |
| `[IMAGE=...]` | `[IMAGE=...]` | Все символы должны быть латинскими |

### Симптомы

- Маркеры не распознаются конвертером
- Заголовки остаются обычным текстом (стиль Normal)
- Таблицы не создаются
- Оглавление не обновляется (элементы не найдены)

### Как проверить

```bash
cd tests
python check_cyrillic_markers.py
```

Скрипт просканирует файлы в `examples/` и покажет проблемные маркеры.

### Как исправить автоматически

```bash
cd tests
python fix_cyrillic_markers.py
```

**Что делает скрипт:**
1. Создаёт бэкап каждого файла (`.txt.backup`)
2. Заменяет кириллические символы в маркерах на латинские
3. Проверяет результат и показывает отчёт

### Пример работы

```
✏️  report_08_project.txt
    Исправлено замен: 5
    Строка 1: [Н1] → [H1]
    Строка 4: [Н2] → [H2]
    Строка 5: [ТABLE_START] → [TABLE_START]

✅ Все файлы исправлены успешно!
```

### Как избежать проблемы

| Действие | Рекомендация |
|----------|--------------|
| Набор маркеров | Переключайтесь на **английскую раскладку** |
| Копирование из Word | Используйте «Вставить как текст» или набирайте вручную |
| Перед конвертацией | Запускайте `fix_cyrillic_markers.py` для проверки |

### Для отката изменений

```bash
# Windows
copy examples\file.txt.backup examples\file.txt

# Linux/Mac
cp examples/file.txt.backup examples/file.txt
```
